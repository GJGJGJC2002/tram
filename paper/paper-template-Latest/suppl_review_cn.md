## A. 实现细节

### A.1 SA-LHMR 实现细节

SA-LHMR 的滑动窗口优化采用 Adam 优化器，每个窗口迭代 50 步，学习率 1e-2。FK Root Correction 中，静态关节判定阈值为置信度 > 0.5 且帧间位移 < 3cm。Contact-Aware IK 中，穿透容差 ε = 2cm；优化目标同时包含接触损失、姿态正则化（权重 0.01）和时间平滑约束（权重 0.05），均使用 Geman–McClure 鲁棒核以抑制离群深度估计的影响。窗口重叠区域的高斯融合带宽 σ = 5，与窗口步长一致，保证窗口边界处的平滑过渡。度量深度由 Metric3D v2 每 5 帧计算一次，并在窗口内复用同一关键帧深度图以保持空间一致性。

### A.2 MO-SLAM 实现细节

MO-SLAM 基于 DROID-SLAM 进行三处修改。（1）**强制关键帧注入**：用 WarmstartMotionFilter 替换原始 MotionFilter，绕过光流选帧，直接将渲染间隔（每 5 帧）对应的帧设为关键帧，并注入首轮 SLAM 的 SE3 位姿和视差图作为热启动；同时设置 keyframe_thresh = 0 禁止 Frontend 移除任何关键帧。（2）**自适应图像替换**：对每个关键帧计算背景区域（非人体区域）的灰度拉普拉斯方差作为纹理得分；当得分低于阈值 τ 时使用渲染图像替换原始图像，否则保留原始 masked 图像。（3）**人体区域置信度抑制**：无论使用哪种图像，在 Frontend 和 Backend 的 DBA 求解器中均将人体 mask 区域的置信度权重置零，实现"几何层面利用、像素层面抑制"的分离设计——渲染网格增强 CNN 特征提取，但不干扰像素级位姿优化。

## B. 消融可视化

在主论文的消融表中，我们展示了在 EMDB2 上的定量消融结果。这里我们提供定性可视化来补充那些数字，并提供对每个组件贡献的直观理解。

### B.1 SA-LHMR 组件效果

图 S1 展示了 SA-LHMR 在 4 个 EMDB2 序列上的消融对比。每行对应一个序列，5 列从左至右分别为：原始输入帧（Input）、初始深度偏移可视化（Depth Offset）、去掉 FK Root Correction 的结果（w/o FK Root Correction）、去掉 Contact-Aware IK 的结果（w/o Contact-Aware IK）、完整模型（Ours）。第 3–5 列采用时间色编码（蓝→绿→橙→红）将多帧 SMPL 网格叠加在输入图像上，以便直观观察运动轨迹随时间的变化。

**图 S1：SA-LHMR 组件的定性消融。** Depth Offset 列中，红色标注可视化了初始相机参数估计误差导致的脚部位置偏移——当相机深度估计不准确时，人体根轨迹存在显著偏差。这正是 FK Root Correction 和 Contact-Aware IK 需要解决的问题起点。

**FK Root Correction（FK 根位移校正）：**
对比第 3 列（w/o FK）与第 5 列（Ours）可以清楚看到 FK 的效果。在第 1 行（张臂站立）和第 2 行（弯腰蹲起）序列中，去掉 FK 后多帧叠加的脚部位置出现显著横向偏移，网格在地面上产生明显滑步；而完整模型中脚部在相邻帧间紧密重合，接触位置在时间上保持稳定。在第 3 行（背面行走）中，去掉 FK 的结果显示蓝色（当前帧）与橙色/绿色（历史帧）的网格之间脚步位置不一致，出现"漂浮"效果；完整模型则呈现连贯、自然的前进步态。这表明 **FK Root Correction 通过前向运动学检测静态关节并校正根位移，在初始相机参数严重错误时尤其关键——它能从运动学层面初步还原正确的运动轨迹，显著消除滑步伪影**。

**Contact-Aware IK（接触感知逆运动学）：**
对比第 4 列（w/o IK）与第 5 列（Ours），可以看到 IK 对运动细节精度的提升。在第 3 行（背面行走，地面有落叶的室外场景）和第 4 行（正面行走，街道场景）中，去掉 IK 后多帧叠加的脚部区域出现模糊扩散——脚部未能精确贴合地面，部分帧中脚部穿透地面或悬浮于地面之上（注意第 4 列脚底与地面的间隙/穿透差异）。完整模型中脚部轮廓在地面接触点处更加清晰紧致，多帧脚部位置保持与场景深度一致。这说明 **Contact-Aware IK 通过深度引导的逆运动学优化，将接触关节调整到场景表面上，保证了人体运动与场景的物理交互性，提升了脚-地面接触等运动细节的精度**。

### B.2 MO-SLAM 组件效果

图 S2 展示了 MO-SLAM 两个关键设计的消融对比，共 4 个子图分为左右两组。每个子图包含一个 3D 相机轨迹图（灰色 = GT，绿色 = Ours，蓝色 = 消融变体）和一个粉色边框的内嵌图展示对应的运动增强输入图像。左侧两个子图对比 Timestep Color Encoding 的效果（室外 + 室内场景），右侧两个子图对比 Adaptive Image Replacement 的效果。

**图 S2：MO-SLAM 组件的定性消融。** 左组：去掉 Timestep Color Encoding 后，渲染网格统一为灰色（见内嵌图），蓝色轨迹在两个场景中均严重偏离 GT；Ours（绿色）则紧密贴合。右组：去掉 Adaptive Image Replacement 后，在背景纹理丰富的场景（右下子图）中蓝色轨迹出现显著漂移。

**Timestep Color Encoding（时间步颜色编码）：**
如图 S2 左组内嵌图所示，没有黄金角度 HSV 颜色编码时，所有帧的渲染 SMPL 网格呈统一灰色外观。当人体在连续帧中移动时，这些灰色网格在图像中互相遮挡，形成一大片颜色均匀、缺乏纹理变化的区域。DROID-SLAM 的特征匹配依赖帧间的视觉差异来建立对应关系，而这片无明显特征的灰色区域不仅无法提供有效的匹配线索，反而干扰了特征提取网络对真实场景特征的编码——模型难以区分哪些像素属于哪一帧的网格。从 3D 轨迹上看，蓝色轨迹（w/o Timestep）在室外场景（左上）中出现剧烈飘逸，在室内场景（左下）中同样严重偏离 GT。相比之下，Ours（绿色）通过为每帧网格赋予独特的 HSV 颜色（如右组内嵌图所示的绿→黄→橙→红渐变），使得不同时刻的网格在视觉上可区分，为 SLAM 提供了帧间无歧义的对应信号。

**Adaptive Image Replacement（自适应图像替换）：**
如图 S2 右组所示，去掉自适应图像替换后，所有强制关键帧无条件使用渲染图像。在左侧子图的室外场景中，由于原始背景纹理本就较少（人体占据画面主体），渲染图像与 masked 原图的差异不大，因此蓝色轨迹与绿色轨迹仍基本重合。然而在右侧子图的室内场景中，背景包含丰富的场景纹理（门框、办公椅、地面纹理等），此时无条件覆盖背景会将这些高质量的自然特征替换为合成的 SMPL 表面，反而劣化了 SLAM 的特征匹配质量——蓝色轨迹出现显著漂移，在轨迹后半段与 GT 产生明显偏差。自适应策略通过拉普拉斯方差评估背景纹理丰富度：在纹理匮乏时使用渲染图像以注入几何线索，在纹理丰富时保留原始图像以利用更优质的自然特征，从而在两种场景下都保持稳定的相机估计精度。
